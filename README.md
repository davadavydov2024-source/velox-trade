уже после него (или поверх текущего состояния, если предыдущий уже применён).

## Новые файлы
- src/app/profile/case-history/page.tsx — история открытий кейсов в профиле

## Изменённые файлы
- src/lib/cases.ts — добавлена getMyCaseOpenings(uid) для истории
- src/app/api/cases/open/route.ts — антиспам-кулдаун 1.5с между открытиями
  (lastCaseOpenAt на профиле пользователя)
- src/app/case/[id]/page.tsx — ПОЛНОСТЬЮ переписан: теперь при открытии
  запускается горизонтальная рулетка (CS:GO-style), которая крутится ~4.2с и
  останавливается на уже честно определённом сервером предмете — результат
  известен ДО начала анимации, сама прокрутка нужна только для эффекта/интриги
- src/app/profile/layout.tsx — пункт меню "История кейсов" в профиле
- src/components/MobileTabBar.tsx — вкладка "Кейсы" в мобильной нижней навигации
  (теперь 5 вкладок: Каталог, Кейсы, Продать, Чаты, Профиль)
