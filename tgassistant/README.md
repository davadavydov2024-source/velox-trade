# Telegram Business-ассистент

Бот подключается к твоему аккаунту (Telegram Business) и реагирует на команды с точки в личных чатах:
`.help`, `.love`, `.sticker`, `.mute` и т.д. Плюс меню и подписки (PREMIUM / VIP за Telegram Stars) в самом боте.

## Запуск
1. @BotFather → твой бот → **Bot Settings → Business Mode** → включить.
2. Установи зависимости и ffmpeg:
   ```
   pip install -r requirements.txt
   sudo apt install ffmpeg      # для .audio .voice .volume .fast .krom .blur .compress
   ```
3. Заполни `.env` (BOT_TOKEN, ADMIN_ID), запусти: `python main.py`
4. В Telegram: Настройки → Telegram для бизнеса → Чат-боты → укажи бота и выдай права: отвечать, удалять сообщения,
   читать сообщения, менять имя профиля. Telegram Premium для подключения больше не нужен (с мая 2026; если пункта нет — обнови Telegram).
5. Напиши боту /start — откроется меню.

## Удалённые и изменённые сообщения
`.startsave` или `/startsave` в боте (PREMIUM) — бот присылает вам в личку удалённые и изменённые сообщения собеседников (текст и файлы по file_id). Хранится 7 дней, `.clearsave` стирает чат, `.stopsave` выключает. Сообщения с защитой от пересылки не сохраняются; фото/видео с таймером и «одноразовые» бот не перехватывает.

## Тарифы
- FREE: основные, развлечения, игры, серии, управление
- PREMIUM: + анимации и медиа
- VIP: + модерация, профиль и авто (.panic, .autoread, .timeprofile …)
- `.spam`: обычным пользователям до 10 000 сообщений за раз (SPAM_MAX), потом перерыв 20 минут (SPAM_COOLDOWN, секунды); `.stopspam` останавливает. Telegram сам ограничивает скорость отправки, а при большом спаме может ограничить аккаунт.
- Админ (ADMIN_ID) всегда VIP и без лимитов (.spam, .xaxa, .bomb, .stairs, .wave, .letters). В любом личном чате можно подарить подписку собеседнику: `.give vip 30` (или `.give user_id premium 7`), снять `.revoke`, список `.subs`. Выдать вручную: `/give user_id premium|vip [дней]`, снять: `/revoke user_id`,
  список: `/subs`, статистика: `/stats`. Цены в звёздах: PREMIUM_STARS / VIP_STARS в `.env`.

## Структура
- `app/registry.py` — реестр команд (меню и `.help` строятся из него автоматически)
- `app/cmds/*.py` — команды по разделам; новая команда = функция с декоратором `@command(...)`
- `app/business.py` — приём business-сообщений и диспетчер, `app/menu.py` — меню, оплата, админка

## Хостинги с папкой /data
Если на хостинге писать можно только в `/data`, бот сам кладёт туда базу и временные файлы. Свою папку можно задать переменной `DATA_DIR`. ffmpeg для медиа-команд подтягивается автоматически через `imageio-ffmpeg`.

## Пробный период
При первом подключении выдаётся PREMIUM на `TRIAL_DAYS` дней (по умолчанию 3, `0` — выключить).

## Хостинг (бот должен работать 24/7)
Бот использует polling — ему нужен постоянно работающий процесс, статический IP не нужен.
```
sudo apt update && sudo apt install -y python3-venv ffmpeg unzip
unzip tgassistant.zip && cd tgassistant
python3 -m venv venv && . venv/bin/activate
pip install -r requirements.txt
python main.py
```
Чтобы бот жил после закрытия терминала и поднимался после перезагрузки — `/etc/systemd/system/tgbot.service`:
```
[Unit]
Description=Telegram assistant bot
After=network-online.target

[Service]
WorkingDirectory=/home/USER/tgassistant
ExecStart=/home/USER/tgassistant/venv/bin/python main.py
Restart=always
User=USER

[Install]
WantedBy=multi-user.target
```
`sudo systemctl enable --now tgbot` · логи: `journalctl -u tgbot -f`
Файл `data.db` (подписки, настройки) нужно сохранять — на хостингах с временной файловой системой он пропадает при перезапуске.

## GitHub
GitHub сам по себе бота 24/7 не хостит — он хранит код и умеет автоматически выкатывать его на ваш сервер.
```
git init && git add . && git status      # убедись, что .env и data.db НЕ в списке
git commit -m "init" && git branch -M main
git remote add origin git@github.com:USER/tgassistant.git   # репозиторий — только Private!
git push -u origin main
```
На сервере: `git clone` репозитория в `~/tgassistant` (для private — deploy key), создать `.env`, venv и systemd-сервис (см. выше).
Автодеплой: `.github/workflows/deploy.yml` + секреты SSH_HOST, SSH_USER, SSH_KEY в настройках репозитория.

## Самый простой запуск
- Windows: установи Python (галочка "Add to PATH"), распакуй архив, дважды кликни `start.bat`.
- Linux / Mac / Termux на телефоне: `./start.sh`
Бот работает, пока включено устройство и открыто окно.

## Управление спамом
`/spammers` — кто сейчас спамит, `/stopspam ID` или `/stopspam all` — остановить (в чате: `.stopspam ID`). Пользователь получает уведомление и может запустить спам снова без перерыва. Доступно админу и мини-админам.

## Мини-админы
`/addmod ID`, `/delmod ID`, `/mods` (или `.addmod`, `.delmod`, `.mods` в личном чате). Мини-админ: все функции без лимитов и платных ограничений, видит `/admin`, `/subs`, `/stats`, но не может выдавать/снимать подписки и назначать других.

## Админ: подарки подписок
`.premium 30` / `.vip 30` в чате с человеком — быстрая выдача.
- В боте: `/admin` (панель), `/give ID premium|vip [дней]`, `/revoke ID`, `/subs`, `/stats`.
- Можно ответить на пересланное сообщение человека: `/give vip 30` (если у него не скрыт профиль пересылки).
- В любом личном чате: `.give vip 30`, `.revoke`, `.subs`.

## Админ-панель (`/admin`)
Кнопки: подписки, статистика, пользователи, топ, спам, баны, промокоды, рассылка, команды, техработы, цены, экспорт. Полный список команд — `/adminhelp`.
- Пользователи: `/users`, `/user ID` (карточка), `/top`, `/ban ID [причина]`, `/unban ID`, `/bans`.
- Команды: `/disablecmd имя` и `/enablecmd имя` (для всех), `/blockcmd ID имя` и `/unblockcmd ID имя` (одному пользователю).
- Промокоды: `/newpromo КОД premium|vip ДНЕЙ ЛИМИТ`, `/promos`, `/delpromo КОД`; пользователи вводят `/promo КОД`.
- Рассылка: `/broadcast текст` (предпросмотр и подтверждение). Техработы: `/maintenance on|off`. Цены: `/setprice premium|vip звёзды`. Выгрузка: `/export` (CSV).
- Мини-админам доступны только просмотр (`/stats`, `/users`, `/user`, `/top`, `/subs`) и остановка спама.

## Рефералы
`/ref` — личная ссылка. Когда друг по ней запустит бота и подключит его, пригласивший получает +`REF_DAYS` дней PREMIUM (по умолчанию 3).

## Новые команды
`.spoiler`, `.mono`, `.bq` (оформление текста), `.roll 2d6+3`, `.days 31.12.2026`, `.fact`, `.color #ff8800`, `.poll вопрос | вариант | вариант`.

## Удалённые и изменённые сообщения (v7)
Сохранение включено по умолчанию для всех, в том числе на FREE (`/stopsave` или `.stopsave` — выключить, `/startsave` — включить).
В личку с ботом приходит: кто (имя, @username, ID), когда отправил и когда изменил/удалил, **было → стало**, а для удалённых ещё и прошлые версии после правок.
Работает только для сообщений, пришедших после включения бота, и только если вы хотя бы раз нажали /start в боте (иначе бот не может вам писать).
Проверка: `/diag` в боте или `.diag` в любом чате — покажет тариф, права бота, время последних событий и ошибку доставки, если она была.
Фото и видео с таймером бот не перехватывает.

## Пользователи в админке (v7)
`/users` — нумерованный список с @username. Отправьте номер (например `3`) — откроется карточка с кнопками: бан/разбан, PREMIUM/VIP, отобрать подписку, дать/снять мини-админку. Мини-админам карточка доступна только для просмотра.

## Ошибки
Необработанные ошибки бота приходят админу в личку (не чаще раза в 10 минут на одинаковую). Версия — `/version`.

## Меню бота (v9)
Главное меню: Подключение, Команды (разделы с переключением ⬅️ ➡️), Тарифы, Профиль, Промокод, Друзья, Диагностика, О боте, Админка (для админов).
Команды меню Telegram (`/`) настраиваются автоматически, для админа добавляются `/admin`, `/users`, `/stats`, `/spammers`.
Подключение: Настройки → Изменить профиль → Автоматизация чатов → @бот. Имя бота подставляется автоматически.

## Админка v10
`/admin` — панель, которая обновляется на месте (без потока новых сообщений): сводка, пользователи, поиск, подписки, статистика, топ, спам, баны, промокоды, рассылка, настройки, цены, команды, техработы, экспорт, бэкап БД, журнал действий.
- Пользователи: фильтры (все / платные / баны / мини-админы), `/find @ник|имя|ID`, номер из списка открывает карточку.
- Карточка: PREMIUM 7/30 д, VIP 30/90 д, отобрать подписку, бан/разбан, мини-админка, отключить/вернуть спам, сбросить перерыв спама, написать (`/msg ID текст`).
- Настройки без перезапуска: пробный период, бонус за друга, лимит и перерыв спама, длительность подписки (`/set имя значение`), цены (`/setprice`).
- `/backup` — копия базы файлом (подписки, настройки). Делайте её перед обновлением на хостинге. `/log` — кто что сделал.

## Обновление одной командой (Windows)
Скачайте новый архив в «Загрузки» и запустите `update.bat` (двойной клик) или в PowerShell из папки проекта: `powershell -ExecutionPolicy Bypass -File .\update.ps1`.
Скрипт сам берёт самый свежий `tgassistant*.zip`, заменяет файлы (не трогая .env, venv, базу), проверяет, что секреты не попали в коммит, делает `git commit` и `git push`. После этого нажмите «Передеплоить» на хостинге.

## Подписки (v11)
- **КОМБО PREMIUM+VIP** — отдельная кнопка в «Тарифах», по умолчанию 10⭐ (`BUNDLE_STARS`, меняется в админке: 💰 Цены или `/setprice combo 10`). Выдаёт VIP, а он включает всё из PREMIUM.
- Подарок админа: `/give ID premium|vip|combo [дней]`, в чате `.premium`, `.vip`, `.combo`, кнопки в карточке пользователя. `/give ID free` снимает подписку.
- Исправлено: покупка или подарок низшего тарифа больше не понижает активный высший (его продлевают); при апгрейде остаток дней не сгорает; повторная доставка одного платежа не начисляет подписку дважды (журнал платежей).
- Пользователю приходит предупреждение за сутки до окончания и сообщение, когда подписка закончилась.
- Админ: `/payments` — платежи, `/refund ID_платежа` — вернуть звёзды и снять подписку.

## Новые команды v11
Гороскоп и даты: `.horo .zodiac .age .moon`. Весёлое: `.nick .emoji .shrug .tableflip .lenny .kao .dart .basket .football .bowl .shuffle`.
Текст и шифры: `.rot13 .caesar .tobin .frombin .lorem`, числа: `.sort`. Игра: `.матем` (устный счёт).
Меню команд теперь разбито на разделы «Текст и шифры» и «Числа, даты, мир».

## Подписки v12: PREMIUM и VIP — независимые
- У человека может быть **обе подписки сразу**, у каждой свой срок. Действует самая высокая из активных; когда VIP закончился, PREMIUM продолжается, если ещё идёт.
- **КОМБО** (по умолчанию 10⭐) выдаёт обе подписки сразу. Если купить PREMIUM и VIP по отдельности — результат тот же, подписки просто складываются. Повторная покупка продлевает.
- **Подарок другу за звёзды:** Тарифы → «Подарить подписку другу» → бот присылает одноразовый код, друг вводит `/promo КОД`.
- Админ: `/give ID premium|vip|both [дней]`, `/give ID premium 30 vip 60` (две сразу с разным сроком), `/revoke ID [premium|vip]`, в чате `.give`, `.premium`, `.vip`, `.both`; `/giftall both 7` — подарить всем (с подтверждением); `/expiring [дней]` — у кого скоро кончается; `/refund` возвращает звёзды и снимает именно оплаченные дни (подарок — удаляет код).
- Промокоды: `/newpromo КОД premium|vip|both ДНЕЙ ЛИМИТ`.
- Старые подписки (одна на человека) при первом запуске переносятся автоматически. Перед обновлением нажмите в админке «💾 Бэкап БД».
- Исправлено: одноразовый код нельзя активировать двумя людьми одновременно; возврат платежа не обнуляет подписку, купленную отдельно.

## Поиск музыки (v13)
- **Инлайн:** в любом чате набрать `@имя_бота название песни` и выбрать результат — в чат уйдёт аудио (30-секундный фрагмент) и кнопка «Слушать полностью».
  Нужно один раз включить в @BotFather: `/setinline` → выбрать бота → текст-подсказка, например «Название песни».
- **Команда:** `.music название` в любом личном чате отправляет первый найденный трек.
- Источник — каталог Deezer (бесплатный API без ключа): доступны только 30-секундные фрагменты и ссылка на полную версию. Полные треки бот не скачивает.
- Админ: `/musictest` проверяет, достаёт ли сервер до каталога.

## Звёзды бота → подарок админу (v14)
`/stars [резерв]` или кнопка «⭐ Звёзды → подарок» в `/admin` показывает баланс звёзд бота и доступные подарки Telegram (🧸 и др.). Можно выбрать один подарок или «Потратить всё» — бот отправит подарки вам со своего баланса (всегда с подтверждением, действие пишется в журнал).
Резерв (`/stars 200`) остаётся на балансе для возвратов `/refund`. Нужен свежий aiogram (`pip install -U aiogram`) — на хостинге он ставится при деплое.
